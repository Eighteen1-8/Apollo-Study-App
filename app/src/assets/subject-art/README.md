# Subject art

Microsoft Fluent Emoji, animated set (https://github.com/microsoft/fluentui-emoji-animated, `main`, downloaded
2026-11-10), resized to 104px by `app/scripts/fetch_subject_art.py`: `<key>.webp` is the first frame (shown at rest),
`<key>.anim.webp` the animation (played on hover). The list of icons lives in that script and in
`app/src/components/subjectIcons.ts`; re-run the script after changing it.
